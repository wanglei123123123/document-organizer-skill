# PC应用宝(PCYYB)专项测试检查矩阵

> 本文件为 PC应用宝 项目定制的完整测试检查矩阵。
> 覆盖**方法与规范、系统层、业务层、性能、数据上报、安全与合规**六大分类。
> 每条检查项标注了测试方法来源、涉及场景、以及与通用测试方法论的映射关系。
>
> **使用方式**: 每次需求提测/版本发布前，逐项核对此表，标记"是否涉及"和"通过/不通过"。

## 使用说明

### 1. 每次需求提测时

```
① 阅读需求文档
② 逐行扫描本检查矩阵,标记"是否涉及"
③ 对"涉及"的项目设计对应测试用例
④ 执行测试并标记结果
```

### 2. 版本发布前

```
① 汇总所有涉及项的测试结果
② 检查是否有遗漏的检查项
③ 重点关注: 功能开关(B-SWITCH)、弱网断网(S-NET)、账号切换(B-LOGIN)
④ 输出版本质量报告
```

### 3. 新增需求时

```
① 评估新需求涉及本矩阵的哪些检查项
② 如果涉及新的检查维度,补充到本文件中
③ 更新版本号和变更日志
```
