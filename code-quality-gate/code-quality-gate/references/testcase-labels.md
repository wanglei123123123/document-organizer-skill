# 应用宝用例标签规范（Test Case Label Specification）

> 本文是 PCYYB（PC 应用宝）用例标签体系的**权威规范**，解决用例跨渠道/跨产品复用与维护成本问题。
> 所有用例的标签填写必须遵循本规范；`testcase-template.md` 中的"优先级"字段为本规范的**子集**。

---

## 一、背景与目标

### 问题
随着 PC 应用渠道和产品类型扩展，主端功能在不同场景上可复用，用例体积呈倍数扩张：
1. 相同用例需要在不同的渠道、产品里各维护一份
2. 集成用例需要跨多个目录
3. 可复用场景未做梳理

### 解决目标
通过**统一的标签体系**实现：
- 同一条用例通过标签区分"适用端"和"适用阶段"，一处维护多处复用
- 集成用例通过标签过滤，不再依赖目录
- 可复用场景用标签显式声明

---

## 二、标签分类总览

标签分为 **5 类**：

| # | 类别 | 是否必填 | 标注阶段 | 标签说明 |
|---|------|---------|----------|----------|
| 1 | **用例优先级** | ✅ 必填 | 用例编写阶段 | 用例执行的优先级 |
| 2 | **是否自动化** | ⚪ 预留 | 自动化用例编写阶段 | 已实现的自动化用例 |
| 3 | **所属端** | ✅ 必填 | 用例编写阶段 | 该条用例适用的端 |
| 4 | **适用阶段** | ✅ 必填 | 用例编写阶段 | 该条用例适用的测试阶段 |
| 5 | **所属测试方** | ⚪ 选填 | 用例编写阶段 | 用例维护方和执行方（腾讯侧不填；虎牙侧填"虎牙侧"） |

## 三、标签字典

### 3.1 用例优先级（必填，有且仅有一个）

| 标签 | 占比（建议） | 适用场景 | 字段说明 |
|------|-------------|----------|----------|
| **P0** | 15% | 开发自测 / 回归测试 / 集成测试 / 上线前测试 / 耦合功能变更被波及 / 集成用例新合入功能验证 | 1) 需求中明确说明的功能点、入口及操作路径<br/>2) 核心模块主流程（不通过会阻塞其他功能验证或其他路径）<br/>3) 核心功能交叉场景：下载状态一致性/下载能力/不同登录状态<br/>4) 页面 UI 显示不错乱 |
| **P1** | 65% | 增量测试 | 1) 需求中未明确要求但延伸的功能点<br/>2) 功能非主路径（不通过不影响其他用例）<br/>3) UI 界面/用户体验维度<br/>4) 不同版本验证（数据/应用宝/插件/技术框架/SDK） |
| **P2** | 20% | 增量测试 | 1) 异常场景：边界值/频繁操作/网络切换/特殊字符/首启非首启<br/>2) 特殊场景：覆盖安装/清数据/杀进程/硬件环境不支持<br/>3) 覆盖文案等维度（如文字展示错误） |

> 规则：**P0 < P1 < P2**（数字越大优先级越低）；每条用例**有且仅有 1 个**优先级。

### 3.2 是否自动化（预留）

| 标签 | 字段说明 | 适用场景 |
|------|----------|----------|
| **待自动化** | 能实现自动化但还未实现，准备实现阶段 | 准备对该用例实现自动化时 |
| **已自动化** | 已实现自动化，通过验证，可正式替代手工 | 完成自动化且能在集成/冒烟中可靠使用 |
| **已自动化但暂未配置** | 已实现自动化，但暂未配置到流水线，未通过验证，不能替代手工 | 标注已完成自动化实现，但还不能可靠使用 |

### 3.3 所属端（必填，可多选）

> PC 应用宝接入不同渠道，适配不同架构，有 2 个不同产品，统称为"端"。不同端可能存在不同的操作路径。

| 标签 | 说明 |
|------|------|
| **PCYYB** | PC 应用宝主产品（x86） |
| **ARM** | 应用宝 ARM 架构版 |
| **手助** | 手机助手（应用宝另一产品形态） |
| **微软绿色版** | 微软绿色包（x86） |
| **ARM微软绿色版** | 微软绿色包（ARM） |
| **360SDK** | 360 SDK 集成版 |
| **联想SDK** | 联想 SDK 集成版 |

> 一条用例若在多个端复用 → 打上多个"所属端"标签；若路径/预期不同 → 拆成多条用例。

### 3.4 适用阶段（必填，可多选）

| 标签 | 说明 |
|------|------|
| **冒烟** | 冒烟测试用例集（最核心流程） |
| **集成** | 集成测试用例集（含冒烟） |
| **虎牙集成** | 虎牙侧负责执行的集成用例 |
| **微软集成用例** | 微软绿色包专属集成用例 |
| **360集成用例** | 360SDK 专属集成用例 |
| **联想集成用例** | 联想SDK 专属集成用例 |
| **增量** | 增量测试（随需求变更的新增用例） |
| **待审核** | 新编写尚未评审通过 ⚠️ 评审阶段必须与其他适用阶段标签同时存在 |

#### 适用阶段包含关系

```
集成 ⊇ 冒烟
  （集成用例集包含冒烟测试用例集，即所有"冒烟"用例都自动属于"集成"范畴）
```

### 3.5 所属测试方（选填）

| 标签 | 使用规则 |
|------|----------|
| （不填） | 腾讯侧负责的用例 |
| **虎牙侧** | 虎牙侧负责执行并维护的集成用例 |

## 四、标签组合使用规则

### 4.1 核心规则

1. **所属端** 与 **用例优先级** / **适用阶段** 组合使用
2. 每条用例有且仅有 1 个**优先级**
3. **适用阶段** 可多选（如同一用例既是"冒烟"又是"集成"，需同时打两个标签）
4. **待审核** 标签在用例评审阶段必须与其他"适用阶段"标签同时存在
5. **适用阶段字段随用例评审与项目组对齐**

### 4.2 过滤规则模板

| 适用场景 | 标签组合 | 过滤规则 |
|----------|----------|----------|
| PCYYB 主版本集成测试 | 所属端:PCYYB + 适用阶段:集成/冒烟 | 标签包含"集成" or "冒烟"，且包含"PCYYB"，**不包含"虎牙侧"** |
| PCYYB 主版本冒烟测试 | 所属端:PCYYB + 适用阶段:冒烟 | 标签包含"冒烟"，且包含"PCYYB"，**不包含"虎牙侧"** |
| PCYYB 主版本虎牙侧集成 | 所属端:PCYYB + 适用阶段:虎牙集成 | 标签包含"虎牙侧""集成"，且包含"PCYYB" |
| ARM 主版本集成测试 | 所属端:ARM + 适用阶段:集成/冒烟 | 标签包含"集成" or "冒烟"，且包含"ARM"，不包含"虎牙侧" |
| ARM 主版本冒烟测试 | 所属端:ARM + 适用阶段:冒烟 | 标签包含"冒烟"，且包含"ARM" |
| 手助主版本集成测试 | 所属端:手助 + 适用阶段:集成/冒烟 | 标签包含"集成" or "冒烟"，且包含"手助" |
| 手助主版本冒烟测试 | 所属端:手助 + 适用阶段:冒烟 | 标签包含"冒烟"，且包含"手助" |
| 微软绿色包集成测试 | 所属端:微软绿色版 + 适用阶段:集成 | 标签包含"微软集成用例"，且包含"PCYYB" |
| ARM 微软绿色包集成测试 | 所属端:ARM微软绿色版 + 适用阶段:集成 | 标签包含"微软集成用例"，且包含"ARM" |
| 360SDK 集成测试 | 所属端:360SDK + 适用阶段:集成 | 标签包含"360集成用例" |
| 联想SDK 集成测试 | 所属端:联想SDK + 适用阶段:集成 | 标签包含"联想集成用例" |

> **关键设计**：通过标签过滤实现"同一份用例服务多个版本测试"，不再依赖目录分散维护。

## 五、标签在各产物中的书写规范

### 5.1 Markdown 用例集（对应 `testcase-template.md` 格式）

在单条用例的元数据块中新增 **标签** 字段，与"优先级"字段并列：

```markdown
### TC-SEARCH-001: 输入关键词搜索应用

- **优先级**: P0
- **所属端**: PCYYB, ARM, 手助
- **适用阶段**: 集成, 冒烟
- **所属测试方**: （空=腾讯侧）
- **自动化**: 待自动化
- **所属模块**: 搜索 > 搜索输入框
- **测试方法**: 场景法 - 主成功场景
- **前置条件(Given)**: ...

| 步骤 | 操作(When) | 测试数据 | 预期结果(Then) |
|------|------------|----------|----------------|
| 1 | ... | ... | ... |
```

**约束**：
- `优先级` 必填，仅 P0/P1/P2
- `所属端` 必填，多端用英文逗号 `,` 分隔
- `适用阶段` 必填，多阶段用 `,` 分隔，评审前必须含"待审核"
- `所属测试方` 选填，腾讯侧留空或写"腾讯侧"
- `自动化` 预留，未填写时默认为"未自动化"

### 5.2 脑图格式（对应 `testcase-mindmap-format.md` 格式）

脑图节点 `S` 后的 `[label]` 区域按**固定顺序**展示：

```
### S：用例标题 [P0] [PCYYB,ARM,手助] [集成,冒烟] [虎牙侧]? [已自动化]?
```

**顺序规则**：
```
[优先级] [所属端] [适用阶段] [所属测试方]? [自动化]?
  必填      必填      必填       选填          预留
```

- 多值用逗号分隔，**不加空格**（如 `[PCYYB,ARM]`）
- 缺省的选填/预留标签省略对应 `[]`
- 示例：`### S：启动应用宝显示首页 [P0] [PCYYB] [冒烟]`

### 5.3 JSON 结构化输出（评审/生成器内部）

```json
{
  "tc_id": "TC-SEARCH-001",
  "title": "输入关键词搜索应用",
  "labels": {
    "priority": "P0",
    "platforms": ["PCYYB", "ARM", "手助"],
    "phases": ["集成", "冒烟"],
    "test_party": null,
    "automation": "待自动化"
  }
}
```

## 六、标签质量规则（评审时自动检查）

对应 `testcase-review.md` 中新增的 **LABEL-\*** 规则组。

| 规则ID | 检查项 | 严重度 |
|--------|--------|--------|
| **LABEL-01** | 优先级必填且仅允许 P0/P1/P2 | BLOCKER |
| **LABEL-02** | 所属端必填（至少 1 个合法值） | BLOCKER |
| **LABEL-03** | 所属端取值必须在标签字典内（PCYYB/ARM/手助/微软绿色版/ARM微软绿色版/360SDK/联想SDK） | CRITICAL |
| **LABEL-04** | 适用阶段必填（至少 1 个合法值） | BLOCKER |
| **LABEL-05** | 适用阶段取值必须在标签字典内 | CRITICAL |
| **LABEL-06** | 新编写用例评审前必须含"待审核" | CRITICAL |
| **LABEL-07** | 冒烟用例自动检查是否也被标为集成（集成⊇冒烟） | MAJOR |
| **LABEL-08** | 虎牙侧用例的适用阶段应含"虎牙集成" | MAJOR |
| **LABEL-09** | 微软/360/联想 SDK 端的用例应用对应的专属集成标签 | MAJOR |
| **LABEL-10** | 所属端多端时，操作路径/预期若不同应拆分用例（不能简单合并）| CRITICAL |
| **LABEL-11** | 自动化标签取值仅允许：待自动化 / 已自动化 / 已自动化但暂未配置 | MAJOR |
| **LABEL-12** | 优先级分布需符合 15/65/20% 基线 | MAJOR（用例集级） |

## 七、Checklist（用例编写时自检）

### 编写前
- [ ] 确认本条用例覆盖的**所属端**范围（主端 / 多端复用 / 多端拆分）
- [ ] 确认**适用阶段**（冒烟 / 集成 / 虎牙集成 / SDK 专属集成 / 增量）
- [ ] 确认是否需要**虎牙侧**标签

### 编写后
- [ ] 优先级（P0/P1/P2）填写？
- [ ] 所属端至少 1 个合法值？
- [ ] 适用阶段至少 1 个合法值？
- [ ] 新编写未评审的用例是否带"待审核"？
- [ ] 若被标为"冒烟"是否也标"集成"？
- [ ] SDK 专属用例是否标对应的"xxx 集成用例"？
- [ ] 多端用例的操作路径/预期是否一致？否则应拆分

### 用例集级
- [ ] 优先级分布：P0 ~15% / P1 ~65% / P2 ~20%？
- [ ] 是否减少了重复用例（同一场景仅一份，通过多"所属端"标签复用）？

## 九、迁移指引（存量用例上标签）

```
对每条存量用例：

  Step 1  判断归属的主端
    ├── 仅应用宝 x86       → [PCYYB]
    ├── 同时覆盖 ARM       → [PCYYB, ARM]
    ├── 属于手助           → [手助]
    ├── 微软绿色包         → [微软绿色版] or [ARM微软绿色版]
    ├── SDK 集成专属       → [360SDK] or [联想SDK]
    └── 多端完全一致       → 列出全部端

  Step 2  判断适用阶段
    ├── 应用上线必过       → [冒烟, 集成]
    ├── 集成回归需覆盖     → [集成]
    ├── SDK 渠道集成专属   → [微软集成用例 / 360集成用例 / 联想集成用例]
    ├── 虎牙侧负责         → [虎牙集成] + 所属测试方:虎牙侧
    └── 仅增量版本用       → [增量]

  Step 3  校验唯一性
    同一用例在不同端的操作/预期不同? ──是──▶ 拆分为多条用例
                                    ──否──▶ 一份用例，多个 [所属端] 标签

  Step 4  填写自动化状态（可选）
    自动化现状 → 待自动化 / 已自动化 / 已自动化但暂未配置
```
