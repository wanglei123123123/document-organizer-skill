### 维度 D9 — 存储/磁盘/权限边界（业务+系统层，⚠️ 高频漏测）

> 涉及"把东西存起来"（下载、缓存、日志、数据库、截图、导出文件、SharedPreferences/localStorage…）的
> 所有场景都必须覆盖本维度。漏测常导致**下载失败无提示、数据损坏、静默崩溃、用户数据丢失、合规事故**。

#### D9.1 存储空间容量边界

| 子类 | 必测点 | 漏测后果 |
|------|--------|----------|
| **完全满** | 磁盘 0 字节剩余 时写入 | 下载失败/静默崩溃/数据损坏 |
| **临近阈值** | 剩余空间 < 安装包大小 但 ≥ 最低阈值 | 是否预检？提示不及时 |
| **剩余 < 系统保留** | Windows 保留 ~200MB / iOS 1GB / Android 500MB | 系统直接杀进程 |
| **写入过程中变满** | 下载 80% 时被其他进程写满 | 下载失败是否清理临时文件 |
| **跨分区/跨卷** | C盘满但D盘有空间 / SD卡与内部存储 | 是否支持切换存储路径 |
| **虚拟空间** | 虚拟内存/页面文件耗尽（Windows） | OOM / 进程被 OS kill |
| **配额限制** | 企业环境每用户配额 / 云盘配额 / OSS Bucket 配额 | 预检&配额耗尽提示 |

**典型边界值**：
```
0 字节 / 1 KB / 1 MB / 100 MB（临界） / 1 GB / 10 GB / 完全满 / 系统保留阈值
```

#### D9.2 存储权限边界

| 子类 | 必测点 | 平台差异 |
|------|--------|----------|
| **未授权** | 首次使用前未申请存储权限 | Android 13+ 细分读/写/媒体 |
| **拒绝授权** | 用户点击"拒绝" → 后续行为 | iOS 拒后需引导到"设置" |
| **部分授权** | Android 14 "仅选中项目"、iOS "有限访问" | 只能读部分文件 |
| **权限被撤销** | App 运行中用户去系统设置撤销 | 再次读写时的容错 |
| **权限二次申请** | 拒绝后再次申请的节流策略 | Android 拒 2 次后不再弹 |
| **后台读写** | 后台态/锁屏态读写权限 | iOS 限制较严 |
| **文件夹/目录权限** | 只读目录、无执行权限目录、Program Files | 安装路径选择 |
| **UAC/管理员** | Windows UAC 未启用管理员 | Program Files 写入失败 |
| **企业域策略** | 组策略禁止写入 U 盘/网络盘 | 提示 & 降级 |
| **杀软/安全软件拦截** | 360/火绒/Defender 拦截写入 | 是否提示用户手动放行 |

**权限状态机**（每次存储操作前必须判断）：
```
未申请 → 已申请待授权 → 已授权 / 已拒绝 / 部分授权 / 被撤销
                                            ↑
                                     （运行中可能变化）
```

#### D9.3 存储路径边界

| 子类 | 必测点 | 关键边界 |
|------|--------|----------|
| **路径长度** | Windows MAX_PATH=260, NTFS 长路径 32767 | 260 字符临界 / 超长路径 |
| **特殊字符路径** | 中文/空格/emoji/符号 `~!@#$` | 中文路径 `C:\用户\张三\下载` |
| **网络路径** | UNC `\\server\share`、映射盘 Z:、WebDAV | 断网时行为 |
| **符号链接/Junction** | 软链接目标不存在 / 循环引用 | 遍历死循环 |
| **只读介质** | CD-ROM / 只读文件夹 | 必须回退到可写位置 |
| **移动介质** | U 盘拔出 / SD 卡弹出 / 外接硬盘离线 | 运行中设备消失 |
| **容器/沙盒路径** | iOS 沙盒 / Android App 私有目录 / Windows AppContainer | 跨 App 访问受限 |
| **用户目录变更** | 非默认 Documents / OneDrive 重定向 | 路径解析正确 |

#### D9.4 存储并发/I/O 边界

| 子类 | 必测点 |
|------|--------|
| **文件被占用** | 写入目标正在被其他进程读/写（如正在杀毒扫描） |
| **同一文件多进程写** | 竞争锁 / 文件校验失败 |
| **写入过程中断电/杀进程** | 是否写入完整？事务/临时文件策略 |
| **大文件 I/O** | GB 级文件 / 低速磁盘 / 机械盘 vs SSD |
| **高 IOPS** | 短时大量小文件（如缓存批量写入） |

#### D9.5 数据完整性边界

| 子类 | 必测点 |
|------|--------|
| **写入中断恢复** | 下载/导出中断后 → 临时文件是否清理 / 是否可断点续写 |
| **文件校验** | MD5/SHA 校验失败的处理 |
| **部分写入** | 写入 50% 后磁盘满 → 是否留下损坏文件 |
| **版本迁移** | 旧版本数据结构 → 新版本读取（DB schema/JSON 字段新增） |
| **数据清理** | 清缓存/卸载重装后数据是否真的清除 / 残留测试 |
| **备份恢复** | iCloud / 华为云备份恢复后数据完整 |

#### D9.6 本地存储上限

| 存储形式 | 平台上限 | 漏测点 |
|----------|----------|--------|
| **SharedPreferences / UserDefaults** | 无硬限制但不建议 >1MB | 大对象序列化性能 |
| **localStorage** | ~5~10MB（浏览器差异） | 超限抛 `QuotaExceededError` |
| **IndexedDB / WebSQL** | 配额（通常磁盘 50%） | 配额超限降级 |
| **SQLite** | 单表记录数 / DB 文件大小 | >2GB 性能骤降 |
| **Cookie** | 4KB/条，总数浏览器限 180~300 | Cookie 溢出丢失 |
| **Keychain/Keystore** | 键值数量限制 | 满后新增失败 |

#### D9.7 存储边界场景矩阵（综合必测）

| # | 场景 | 预期行为 |
|---|------|----------|
| 1 | 首次使用前未申请存储权限 | 自动申请或引导 |
| 2 | 用户拒绝存储权限 | 不崩溃 + 友好提示 + 设置引导 |
| 3 | 运行中权限被撤销 | 感知变化 + 暂停读写 + 提示 |
| 4 | 磁盘完全满时下载 | 预检失败提示 / 不进入下载 |
| 5 | 下载 80% 时磁盘满 | 暂停 + 提示 + 临时文件清理 |
| 6 | 安装到中文/空格路径 | 功能正常 |
| 7 | 安装到 >260 字符路径（Windows） | 长路径支持 / 或降级提示 |
| 8 | 卸载后数据是否真的清除 | 合规需求：无残留 |
| 9 | 升级时数据迁移 | 旧数据读取 + 新字段兼容 |
| 10 | 文件被杀毒软件锁定 | 识别 + 提示用户处理 |
| 11 | 写入过程中断电重启 | 临时文件清理 + 无损坏数据 |
| 12 | 大量小文件并发写入（如日志） | 不阻塞主流程 |
| 13 | localStorage 超限时 | 降级 + 清理最旧数据 |
| 14 | 卸载时数据保留选项 | 是否弹"保留 vs 删除"选择 |
| 15 | 清缓存后关键数据保留 | 登录态、下载记录等该留的留 |

**评审规则**：`testcase-review COV-STG-*` + `COUP-STG-*`
**代码扫描规则**：`scan-rules STORAGE-*`
**相关场景法备选流**：`case-design-methods.md 3.4` 备选流 B/C（存储满 → 失败可恢复/终止）

## 四、按资产类型的边界值检测清单

### 4.1 代码扫描时检测的边界值规则

> 来自 `scan-rules.md`，扫描器自动执行：

| 规则 ID | 名称 | 严重度 | 适用语言 |
|---------|------|--------|----------|
| `INPUT-02` | 参数范围校验缺失 | BLOCKER | ALL |
| `INPUT-04` | 字符串长度未限制 | CRITICAL | ALL |
| `NULL-02` | 集合/数组越界访问 | BLOCKER | ALL |
| `NULL-05` | Map/dict.get 无默认值 | MAJOR | Python/Java/JS |
| `BOUND-01` | 循环边界 off-by-one | CRITICAL | ALL |
| `BOUND-02` | 切片/子串越界 | CRITICAL | Python/Java/JS |
| `BOUND-03` | 整数运算溢出 | CRITICAL | Java/C/C++/Python |
| `BOUND-05` | 递归深度无限制 | MAJOR | ALL |
| `BOUND-06` | 集合容量超限 | MAJOR | ALL |
| `PERF-03` | 循环内重复计算 | MAJOR | ALL |
| `PERF-04` | 循环字符串拼接 | MAJOR | Java/Python |

**触发命令**：
```bash
python scripts/code-scanner.py ./src --lang python --output json
```

### 4.2 需求文档扫描时检测的边界值

> 来自 `scan-rules.md REQ-TEXT-01` 和 `requirement-scan-rules.md`：

- **关键词匹配**：最大/最小/不超过/至少/介于/限制为/范围…
- **结构化提取**：Given/When/Then 中的边界参数；约束表中的 min/max/default
- **代码反查**：提取出的边界必须在代码中有对应校验逻辑

### 4.3 用例评审时检测的边界值覆盖

> 来自 `testcase-review.md` 维度二完整性检查：

| 规则 ID | 涉及字段类型 | 必须覆盖的边界 |
|---------|--------------|----------------|
| `COV-B01` | 字符串输入框 | 空 / 1字符 / 最大长度 / 超最大 / 纯空格 |
| `COV-B02` | 数值输入 | 最小-1 / 最小 / 中间 / 最大 / 最大+1 |
| `COV-B03` | 列表/数组 | 0项 / 1项 / 最大项 / 超最大 / 分页边界 |
| `COV-B04` | 时间范围 | 开始前 / 开始时 / 结束时 / 结束后 / 跨零点 / 时区 |
| `COV-B05` | 文件上传 | 空文件 / 1KB / 最大 / 超最大 / 格式不符 |
| `COV-B06` | 频控边界 | 阈值前1次 / 第N次 / 超N次 / 时间窗刚过 |

**触发命令**：
```bash
python scripts/testcase-reviewer.py cases.md --context context.yaml
# 在 context.yaml 中声明 field_types: [input_text, number, list, file]
```

### 4.4 用例生成时输出的边界值结构

> 来自 `testcase-template.md` 第二章「边界值用例」示例：

每条字段必出 5 类边界用例：
- 空输入直接搜索（下确界=空）
- 纯空格输入（不可见空白）
- 最小有效长度（=1字符）
- 恰好达到最大长度（=max）
- 超出最大长度1个字符（=max+1）
- 粘贴超长字符（>>max）
